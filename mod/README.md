# PoliteShop — донат-мод для NeoForge 1.21.1

Игровой мод, интегрированный с сайтом сервера: магазин товаров, корзина,
баланс DC (донат-валюта), команды `/dc` и плейсхолдер `%donatecoin%`.

## Возможности

- **Меню магазина** (команда `/donate` или `/shop`, либо кнопка «$» в инвентаре) —
  товары подгружаются с сайта динамически (`/api/mod/shop`), покупка за DC прямо из игры.
- **Корзина** — купленные товары попадают сюда (`/api/mod/cart`), кнопка
  «Забрать» выдаёт товар через RCON на сервере (`/api/mod/claim`). Та же корзина
  доступна на сайте в личном кабинете (`/account`) и полностью синхронизирована.
- **Баланс DC** — HUD-оверлей в углу экрана + в шапке магазина.
- **Пакеты DC** за реальные деньги — кнопка ведёт на сайт (в игре не оплачиваются).
- **Команды `/dc`** на сервере: `get`, `add`, `take`, `set` (нужен `mod_admin_key`).
- **Плейсхолдер `%donatecoin%`** — через scoreboard-цель `donatecoin`
  (её показывают в табе/сайдбаре большинство плейсхолдер-мостов).

## Авторизация

Клиент берёт токен доступа лаунчера (`Minecraft.getUser().getAccessToken()`) и
отправляет его как `Authorization: Bearer <token>`. Сайт уже проверяет этот токен
(тот же механизм, что и у лаунчера GML) — никаких ручных ключей игрок не вводит.

## Настройка на сервере/клиенте

Конфиг создаётся при первом запуске: `config/politeshop-common.toml`.

```toml
# URL сайта (без завершающего слэша)
siteUrl = "https://ваш-сайт"
# Секретный ключ для команд /dc — ДОЛЖЕН совпадать с mod_admin_key
# в настройках сайта (админка → Настройки). Только на сервере.
adminKey = ""
```

`mod_admin_key` задаётся в админ-панели сайта (Настройки). Оставьте пустым, чтобы
отключить команды `/dc`.

## Сборка из исходников

Требуется JDK 21.

```bash
cd mod
./gradlew build
```

Готовый JAR: `build/libs/politeshop-neoforge-1.21.1-1.0.0.jar`.
Положите его в папку `mods/` и на клиенте, и на сервере.

## Собранный JAR

Уже собранный мод лежит в `public/downloads/politeshop-neoforge-1.21.1-1.0.0.jar`
(доступен по адресу `/downloads/politeshop-neoforge-1.21.1-1.0.0.jar` на сайте).
